# Five Meow Market

## 프로젝트명

Five Meow Market

## 프로젝트 소개

Five Meow Market은 고양이 관련 상품을 둘러보고 구매할 수 있는 반응형 온라인 마켓 서비스입니다. 상품 목록과 상세 정보를 확인하고, 장바구니와 찜 목록을 관리할 수 있도록 구성했습니다.

사용자 인증을 중심으로 로그인, 회원가입, 회원 정보 수정, 비밀번호 찾기 기능을 제공하며, 공지사항·문의·리뷰와 같은 커뮤니티 기능도 함께 제공합니다. 모바일 환경에서도 주요 화면과 인증 모달을 편리하게 이용할 수 있도록 반응형 UI를 적용했습니다.

## 주요 기능

- 상품 목록 및 상품 상세 조회
- 장바구니와 찜 목록 관리
- 로그인 및 회원가입
- 비밀번호 찾기 모달
- 마이페이지 및 회원 정보 수정
- 주문 목록과 주문 상세 조회
- 공지사항, 문의, 리뷰 조회
- 반응형 웹 화면

## 기술 스택

- React
- React Router
- Emotion
- Vite

## 실행 방법

```bash
npm install
npm run dev
```

프로덕션 빌드는 다음 명령어로 실행할 수 있습니다.

```bash
npm run build
```
